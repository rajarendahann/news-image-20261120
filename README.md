This repository is an entry for make.fun's daily news-image competition, summing up Friday 20 November 2026's world news in one image. The competition details can be found at https://make.fun/bounty/news-image-20261120.

## How it works

The `main.py` script is written in Python 3.13 using only the standard library. It is deterministic and generates the repository's `entry.png` (1024x1024) to the directory specified by the `MAKEFUN_OUTPUT_DIR` environment variable, which defaults to `/output`.

## Stories covered

* Russian missiles landing in Poland during Nato postwar-planning drills
* The UK-EU reset summit in Brussels
* Italy's CGIL general strike over wages and services
* The COP31 endgame in Antalya
